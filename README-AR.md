# مساعد الدواء - حزمة البناء الأولية لأندرويد

هذه الحزمة تنقل نسخة الويب الحالية كما هي إلى مشروع Capacitor قابل للبناء سحابياً عبر GitHub Actions.

## الملفات
- `www/index.html`: الكود الأصلي للتطبيق دون إعادة تصميم.
- `package.json`: اعتماديات Capacitor.
- `capacitor.config.json`: هوية التطبيق واسم الحزمة.
- `.github/workflows/android-debug.yml`: سير عمل يبني APK تجريبياً عند تشغيله يدوياً أو عند الدفع إلى فرع main.

## بناء APK
بعد رفع محتويات هذه الحزمة إلى جذر مستودع GitHub، افتح تبويب Actions، واختر Build Android APK، ثم Run workflow. عند النجاح ستجد ملف APK ضمن Artifacts في صفحة تشغيل العملية.

## تنبيه مهم
هذه نسخة تغليف أولية للاختبار فقط. لم تتم بعد إضافة جدولة الإشعارات الأصلية أو إعادة الجدولة بعد إعادة تشغيل الهاتف. لذلك لا تعتبر هذه النسخة منبهاً دوائياً موثوقاً للاستخدام الطبي، ولا توزعها على المرضى قبل استكمال واختبار تكامل الإشعارات والصلاحيات على أجهزة متعددة.
